# Visual polish (invest in presentation)

Goal: a stranger arriving for a book or project should feel *this is intentional*, not *this is a starter template*.

## When this skill applies

Homepage, coming-soon, about/contact, story/project chrome, `assets/style.css`, promotional landing sections.

## Process

1. **Read current surfaces** — `index.md`, `_layouts/default.html`, `assets/style.css`, and the page being changed.
2. **Define one visual direction** — atmosphere, type, accent; encode as CSS variables. Do not layer random trends.
3. **Brand test** — if you removed the nav, would the first viewport still feel like Sarkany Nexus?
4. **Hero discipline** — brand + one promise + optional one CTA; no clutter overlays or card grids in the hero.
5. **Typography & color** — distinctive fonts; avoid purple-gradient / generic Inter dashboard look unless the user insists on keeping current tokens temporarily.
6. **Imagery** — real covers/atmosphere when available; compress assets; never leave multi‑MB PNG heroes.
7. **Mobile pass** — check nav, hero type size, CTA tap targets.
8. **Copy pass** — specific, confident, short. Cut filler.

## Checklist before finishing

- [ ] First viewport has a single clear composition
- [ ] Brand is the strongest text signal on marketing pages
- [ ] No AI-slop motif cluster (purple glow, chip rows, fake stats)
- [ ] Coming-soon (if on) still feels designed, not abandoned
- [ ] Light/dark (if supported) both remain readable
- [ ] No layout shift from missing image dimensions where easy to set

## Out of scope unless asked

Replatforming to React/Astro, adding animation libraries, stock-illustration packs, or third-party page builders.
